   # Локальный AI-Ассистент (NLUX + LM Studio)

   Полнофункциональный чат-бот с локальным запуском моделей, поддержкой мультимодальности, аналитикой и гибкими настройками. Разработан в рамках учебной практики.

   ## 🚀 Как запустить проект

   ### Предварительные требования:
   1. Установленный [Node.js](https://nodejs.org/) (версия 18+).
   2. Запущенное приложение [LM Studio](https://lmstudio.ai/) с загруженной моделью (рекомендуется `phi-3-mini-4k-instruct` или `qwen/qwen3.5-9b`).
   3. В LM Studio должен быть запущен локальный сервер на порту `1234` (кнопка "Start Server").

   ### Установка и запуск:
   1. Склонируйте репозиторий или скачайте архив.
   2. Откройте терминал в папке проекта.
   3. Установите зависимости:
      ```bash
      npm install
      ```
   4. Запустите проект в режиме разработки:
      ```bash
      npm run dev
      ```
   5. Откройте в браузере адрес: `http://localhost:5173`

   ## ✨ Реализованные возможности
   - Потоковая генерация ответов (Streaming) через кастомный адаптер `useAsStreamAdapter`.
   - Загрузка и анализ файлов: изображения (base64) и текстовые форматы (.txt, .py, .json, .csv и др.).
   - Светлая и темная тема с адаптивным градиентным фоном.
   - Встроенная аналитика: графики Chart.js (время ответа, распределение по моделям) и сводные таблицы.
   - Гибкая настройка: Temperature, Max Tokens, индивидуальный системный промпт для каждого чата.
   - Полная поддержка горячих клавиш (Ctrl+Z, Ctrl+X, Ctrl+Shift+S и др.).
   - Полное сохранение состояния (история, настройки, тема) в `localStorage`.

   ## 🛠 Стек технологий
   - **Frontend:** React 18, TypeScript, Vite
   - **UI/Chat:** NLUX (`@nlux/react`, `@nlux/themes`)
   - **Визуализация:** Chart.js, `react-chartjs-2`
   - **Хранение:** LocalStorage API
